📌 PANGUNAHING LAYUNIN

Sistema para sa pagtukoy ng tamang pamasahe, pagsukat ng kita/lugi, pamamahala ng ruta, rider, at order — lahat sa iisang pahina.

🚗 PORTAL / CALCULATOR

  • GPS Sukat: Kumuha ng distansya gamit ang lokasyon sa internet — awtomatikong nakukuwenta ang km
  • Bagong Ruta: Ilagay ang simula, dulo, distansya, at inirerekomendang singil
  • Pagtatakda: Itakda ang uri ng sasakyan, km/litro, presyo ng gasolina, piyesa, layunin sa kita
  • Kuwentahin: Ilagay ang pamasahe → makikita agad kung kumita o lugi
  • Itala: I-save ang biyahe sa listahan → makikita ang kabuuan at progreso
  • Ipadala sa Admin: Ipadala ang datos sa panel ng pamamahala

⚙️ ADMIN PANEL

  • Buod: Bilang ng ruta, rider, bukas na order, kabuuang kita
  • Mga Order: Lumikha, magbago, magkansela, markahan na natapos
  • Mga Ruta: Pamahalaan ang lahat ng ruta — awtomatikong singil kapag pinili
  • Mga Rider: Magdagdag, magbura, itakda ang katayuan (online/abala/offline)
  • Magtalaga: Iugnay ang order sa rider → awtomatikong punan ang ruta
  • Mga Gawain: Subaybayan ang biyahe — tinanggap/natapos/kansela
  • Pananalapi: Kabuuan − gastos − komisyon = malinis na kita
  • Pangkalahatan: Presyo ng gasolina, piyesa, porsyento ng komisyon

💰 PORMULA NG KUWENTA

Distansya → Litro = km ÷ kmBawatLitro
GastosGasolina = Litro × PresyoBawatLitro
PiyesaBawatBiyahe = PiyesaAraw ÷ BilangNgBiyahe
KabuuangGastos = GastosGasolina + PiyesaBahagi
Kita = Pamasahe − KabuuangGastos
✅ Kita > 0 → KUMITA
❌ Kita < 0 → LUGI
