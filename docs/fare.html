📖 TULONG — GABAY SA PAGGAMIT

📍 GPS Tracking: Pindutin ang Realtime GPS → Simulan → Itigil kapag nakarating → Gamitin ang sukat. Kukuwentahin nito ang aktuwal na distansya ng inlakad.

💰 Paano Kuwentahin:
Singil − (Gasolina + Bahagi ng piyesa + upa) = Netong Kita
• Gastos sa Gasolina = (km ÷ km/bawat litro) × presyo ng gasolina
• Bahagi ng Piyesa = (Piyesa/Araw) ÷ Bilang ng oras ng trabaho
• Kung positibo ang resulta = KUMITA ✅ | Kung negatibo = LUGI ❌

🔁 2-Way vs 1-Way: Kapag 2-Way, doblehin ang distansya at konsumo ng gasolina.

📊 Progreso ng Araw: Ipasok ang layunin sa kita bawat araw upang makita kung naabot na ito sa kabuuan ng mga biyahe.

🛣️ Magdagdag ng Ruta: Ipasok ang simula at dulo, pindutin ang Kumuha Distansya sa Mapa para kusang kunin ang layo mula sa internet.

💾 Pag-iimbak: Ang lahat ng datos ay nakatago sa iyong aparato lamang. Pindutin ang I-Export para makagawa ng backup na file.
